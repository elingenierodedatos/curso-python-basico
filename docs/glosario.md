# Glosario

Los términos del curso, con su nombre en inglés. En el trabajo los vas a oír de las dos formas.

| Término | En inglés | Significado |
| --- | --- | --- |
| Acumulador | Accumulator | Variable que junta un resultado dentro de un bucle: una suma, un conteo o una lista |
| Argumento | Argument | Valor que entregas a una función al llamarla |
| Base de datos | Database | Lugar organizado para guardar y consultar datos |
| Bucle | Loop | Bloque de código que se repite (`for`, `while`) |
| Clave primaria | Primary key | Columna que identifica cada fila de una tabla sin repetirse |
| Codificación | Encoding | Regla para guardar texto como bytes; en el curso siempre UTF-8 |
| Conjunto | Set | Colección sin orden y sin valores repetidos |
| Consulta | Query | Instrucción SQL que pide datos a una base |
| Dato faltante | Missing value | Valor que no llegó: vacío, `N/D`, `NA` |
| Diccionario | Dictionary | Colección de pares clave y valor |
| Docstring | Docstring | Texto entre comillas triples que documenta una función o un módulo |
| Entorno virtual | Virtual environment | Instalación de Python aislada para un proyecto |
| Excepción | Exception | Error que ocurre mientras corre el programa y que se puede manejar |
| Flujo de datos | Data pipeline | Serie de pasos que lleva los datos de su origen a un resultado útil |
| Función | Function | Bloque de código con nombre que recibe datos y devuelve un resultado |
| Lista | List | Colección ordenada que se puede modificar |
| Método | Method | Función que pertenece a un valor y se llama con un punto: `texto.strip()` |
| Módulo | Module | Archivo `.py` cuyo contenido se puede importar |
| Parámetro | Parameter | Nombre que una función usa para recibir un valor |
| Prueba unitaria | Unit test | Código que comprueba que una función hace lo que debe |
| Repositorio | Repository | Carpeta de un proyecto con su historial de cambios en Git |
| Sangría | Indentation | Espacios al inicio de una línea; en Python define los bloques |
| Texto | String | Secuencia de caracteres; el tipo `str` |
| Tupla | Tuple | Colección ordenada que no se puede modificar |
| Variable | Variable | Nombre que apunta a un valor |

Las cuatro etapas del proyecto final también tienen nombre propio en la industria: extraer (*extract*), limpiar o transformar (*transform*) y cargar (*load*). Juntas forman lo que se conoce como ETL.
